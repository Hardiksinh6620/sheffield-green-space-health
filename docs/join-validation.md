# Attribute join validation checklist

The methods discussion describes table joins. A reproducible join record should identify the target and join tables, key fields, data types, duplicate keys, unmatched records, one-to-one or one-to-many expectations, and fields retained after joining.

Compare row counts before and after the operation. Report unmatched geographic units and duplicated identifiers rather than silently dropping or multiplying observations. Validate that geographic codes use the same boundary vintage.
